## Open Source & Proprietary Components

The App uses third-party open source software including but not limited to:

- Stellar SDK and Soroban RPC client libraries
- React Native and Expo framework
- Various cryptographic libraries for encryption and key derivation

Source code excerpts for security review are available within the App under **Settings → Audit Our Security Code**. Related security modules/excerpts and documentation may be published in this repository under Apache 2.0 where indicated. The full Android app backend and complete vault contract source remain proprietary by design. On-chain contract IDs are visible on Stellar explorers.
