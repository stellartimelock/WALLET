Delete your account

Sign-in is optional. You can use Sourceify with no account.

This version does not create a Sourceify account on a server. There is no password and no email on the account. Sign in with Stellar stores an id on your phone only. That id is not sent anywhere in this version.

Delete the sign-in

  1. Open Sourceify.
  2. Open Settings.
  3. Tap Sign out.

Sign out deletes the contributor id on that phone. If you never signed in, there is no id to delete.

Delete everything else on the phone

Saved places, settings, offline areas, and pending suggestions stay on the phone until you remove them.

  • Uninstall Sourceify, or
  • Android Settings → Apps → Sourceify → Storage → Clear storage.

Clear storage also deletes the sign-in. A backup file you already exported is a file you hold. Delete that file yourself if you still have it.

Location

Sourceify does not keep a location history. We have no server copy of where you searched. We cannot delete logs that overpass-api.de, gisportal.hrsa.gov, or tiles.openfreemap.org may keep on their own.
