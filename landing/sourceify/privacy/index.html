Privacy

Effective October 3, 2026. This page matches Sourceify version 1.4.1 for Android, package app.stellar.sourceify.

The short version

Sourceify is free. There are no ads. We do not sell your information. We do not share it with advertisers.

You can look up help, call, and get directions with no sign-in. There is no Sourceify account server in this version.

Location

The app asks for location only after you tap Use my location. You can type a city or ZIP instead. If you say no, the rest of the app still opens.

The last place you choose — a city, a ZIP, a dropped pin, or the point from Use my location — stays on this phone so the map and the list can open there next time. That is one place, not a history of where you walked. Saved places are places you chose to keep.

When a search goes online, the app does not send your exact pin. It rounds the point to about 1 kilometer (about 0.01 degrees). A health search sends that rounded point and the search distance. Other online searches send a box around that point. The box is as wide as the distance you picked (about 10 miles unless you change it).

Play’s form calls a point this precise “precise location,” because 1 kilometer is smaller than 3 square kilometers. The search box is “approximate location.” Both are optional. Both are sent only to run the search or to draw the map. They are not used for ads.

Who receives a search area

This version has no Sourceify server. These hosts are called by the app itself, over HTTPS:

  • overpass-api.de — OpenStreetMap places for the rough area you chose.
  • gisportal.hrsa.gov — community health centers, only when a health search runs online. The request uses the rounded point and the search distance.
  • tiles.openfreemap.org — map style, tiles, fonts, and sprites, only after you open the map and data saver allows it. Data saver is on by default and skips map tiles on cellular data. The tile request shows the area on the screen.
  • files.mobilitydatabase.org — a public list of transit feeds, on Wi-Fi when data saver is off. Your location is not sent.
  • api.mobilitydatabase.org — transit feeds for a rough box, only if a Mobility Database token was set when the app was built. This build does not include one.
  • transit.land — transit agencies for a rough area, only if a Transitland key was set when the app was built. This build does not include one.

Map data is © OpenStreetMap contributors. Tiles are © OpenMapTiles and OpenFreeMap. There is no Google Maps key.

The app sends a User-Agent that names Sourceify and the developer site. It does not send your name, a device advertising ID, or a public IP lookup.

Links you tap (a benefit site, the dialer, your own maps app) are opened by the phone. The app’s data layer does not call those sites.

Who the help is for

The first time you open the app, it asks whether you are looking for yourself or for a family, and you can add veteran, youth, women-only, or pets. Those answers stay on this phone. They are used to hide places that do not fit. They are not sent off the phone in this build.

Optional sign-in

Sign in with Stellar is optional. It does not ask for your name, email, or phone number. This build does not include a Stellar Profile server address, so the id stays on this phone. Reputation is a number on this phone. It does not include a name. Sign out deletes the id. See Delete account.

If a later build sets a Stellar Profile address, sign-in can create an id with that service, and community edits can sync. A photo stays on the phone. A sync of edits uses a point rounded to about 1 kilometer, not an exact pin.

Community edits

Suggest a missing place, report wrong info, claim a listing, edit hours, check a place, or answer “Is this still accurate?” In this build those notes stay on your phone. Other people cannot see them, because no review server is configured.

A report does not ask for your name. Do not type your story, your phone number, or an ID number in the note.

A claim can ask for an email on the organization’s own website, a code to the phone already on the listing, or the text of a 501(c)(3) letter. In this version the check is not connected, so that information is not sent. The app keeps at most the last four digits of an EIN on the phone. It is not a profile of you.

What stays on the phone

  • Language, distance units, data saver, and search distance
  • Places you save
  • Areas you save for offline
  • Pending suggestions, reports, claims, and edits
  • The optional contributor id, until you sign out

A backup file is created only when you tap Export backup, and it is shared only if you send it yourself. Import replaces data on that phone only after you confirm.

What we do not collect

We do not collect your name, email, phone number, contacts, photos, health details, messages, or payment information. Searching for a clinic does not send your medical history. There is no analytics SDK and no ads SDK.

We do not sell personal information. We do not share it for advertising or for a data broker.

Children

Sourceify is not directed at children under 13. The store listing is for adults 18 and older. Do not include a child’s name or story in a note.

Delete

There is no Sourceify server account to erase. Sign out deletes the local id. Uninstalling, or clearing the app’s storage, deletes saved places, settings, and pending notes. We cannot delete a search a third-party host already logged, because we do not operate those hosts and we do not keep a copy. Write to us if you need help.
