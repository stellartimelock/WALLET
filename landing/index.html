Vault features, first.

Self-custody tools built for Stellar — lock, vest, cool off, and move assets without handing keys to anyone.
Your keys never leave the device.

  • 🔒

    Time-Lock vaults

    Lock XLM or Stellar tokens until a timestamp you choose. Enforced on-chain by Soroban — no admin key, no emergency exit.

  • ❄️

    Cooling-Off

    Withdrawals need a heads-up first. Start a withdrawal, wait out the cooling-off period, and cancel anytime if it wasn't you.

  • 📈

    Vesting

    Funds unlock in discrete steps — daily, weekly, or monthly. Set an interval, optional start date, and withdraw each chunk as it vests.

  • ⌛

    Dead Man's Switch

    Set a check-in cadence. If you miss it, the vault can release to a beneficiary you named — on-chain, with no custodian in the middle.

  • 👥

    Multi-Sig

    Require multiple approvals before funds move. Shared control without giving anyone your keys.

  • 💎

    Multi-Asset

    Time-lock XLM or any Stellar asset with a trust line. Same vault model, broader asset support on Mainnet.

  • 🔗

    HTLC Available now

    Cross-chain atomic swaps using hash time-locked contracts. Lock XLM that only releases when a counterparty provides a secret passphrase before a deadline. Unlocked for everyone during early access.

  • 🔄

    Swap

    Send, receive, and swap crypto with transactions signed natively on-device — never by a remote server.

  • 👛

    On-device wallet

    Generate or import a Stellar seed. Multi-wallet support and an address book — all bound to your device keystore.

Frequently asked questions

Is this a custodial wallet? +

No. Stellar TimeLock is non-custodial. Private keys never leave your device. StellarTimeLock, LLC never holds user funds, keys, or signing authority.

How do Time-Lock vaults work? +

Time-Lock Vaults are enforced by a Soroban smart contract on Stellar. There is no admin key and no emergency exit — what you lock stays locked until the unlock timestamp you chose.

What is Cooling-Off? +

Cooling-Off vaults require a withdrawal notice first. Start a withdrawal, wait out the cooling-off period, and cancel any time if it wasn't you — a delay that helps stop impulsive or unauthorized exits.

Will this website ever ask for my seed phrase? +

Never. This is an informational landing page for our mobile app. StellarTimeLock, LLC will never ask for your secret seed or recovery phrase on this website. Keep your keys in the app, on your device.

Where can I review the security reference? +

Security modules and excerpts, contract IDs, and legal docs are in WALLET. Full app backend and complete vault contract source remain proprietary. On-chain contract addresses are verifiable on Stellar explorers. Responsible disclosures: StellarTimeLock@gmail.com.
